# Third-party visual source

The Sydney UI includes an adaptation of [Themefisher Constra](https://github.com/themefisher/constra-bootstrap) at commit d75c9a80d13618031f78aa5abbd2c5e3ac592402.

Licence: MIT. The unmodified notice is included in public/licenses/constra-MIT.txt and at the start of public/site.css.

Selected upstream theme/css/style.css ranges inform the adapted existing selectors: contact strip 578–610; white header 703–738; buttons 499–548; image banner 1218–1238 and 1421–1475; services 1663–1713 and 1811–1819; gallery 1888–1969; footer 2356–2450. The adapter maps these rules to existing Mel One component classes, changes the accent to blue, uses the existing sans font stack and adds responsive/localized/accessibility treatment.
